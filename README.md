## Organisation

Chaque étude a son dossier `projets/<étude>/` : `analyse.py` calcule les résultats à partir des données brutes, et `excel/graphiques/` contient les graphiques du site, faits dans Excel.

## Le site

HTML, CSS et JavaScript écrits à la main, sans framework. Le fond de chaque page est un nuage de points interactif (`assets/fond.js`) : une régression est calculée en direct sous la souris.
