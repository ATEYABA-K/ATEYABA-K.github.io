Tuto Excel · 30 min

Refaire les graphiques du projet dans Excel.

« Automatisation d'un reporting Insee » : chaque graphique de l'étude, clic par clic, avec les formules. Ouvrez l'exercice et suivez.

Exercicereporting-insee-exercice.xlsx, les données, rien n'est fait Corrigéreporting-insee-corrige.xlsx, la version finie, celle du site CSV pour Power BIun fichier par graphique ↗

Ce que vous allez pratiquer : courbes avec marqueurs · Power Query : un import qui s'actualise · Actualiser tout.

00 · Avant de commencerTrois réglages

  • Téléchargez le fichier exercice et ouvrez-le dans Excel. Les cellules jaunes sont à remplir, les graphiques sont à construire.
  • Le fichier corrigé contient la version finie : c'est de là que viennent les graphiques du site. Ouvrez-le à côté pour comparer.
  • Les formules sont écrites pour Excel en français : les arguments sont séparés par ;. En anglais, remplacez ; par , et utilisez le nom entre parenthèses.
  • Recopier une formule vers le bas : sélectionnez la cellule, puis double-cliquez sur le petit carré en bas à droite.

Les couleurs du portfolio : bleu #1F3864, orange #D9542B, gris #8FA0C2. Pour les appliquer : clic droit sur une série → Mettre en forme une série de données → pot de peinture Remplissage et trait → Remplissage uni → Couleur → Autres couleurs → onglet Personnalisées → champ Hex.

Dans le projet, un robot télécharge et nettoie le fichier Insee chaque mois. Ici, on fait le graphique du reporting.

  1. En B9, recopiez vers C9 et D9.

02 · Onglet csv/adoption_ia.csvAutomatiser sans coder : Power Query

L'équivalent Excel du robot : un import qui se met à jour en un clic quand le fichier change.

2.1 L'import

  1. Classeur vide → Données → À partir d'un fichier texte/CSV → adoption_ia.csv → Charger.
  2. Faites le graphique à partir de ce tableau (étape 1.2).

2.2 La mise à jour

  1. Remplacez le CSV par une version plus récente, même nom, même dossier.
  2. Données → Actualiser tout : le tableau et le graphique se mettent à jour seuls.

✅ Vérifiez : Modifiez une valeur dans le CSV, actualisez : le graphique bouge sans rien refaire.

BonusExporter un graphique
